# Vet an AI learning resource or tool

Goal: protect the learner's time and money. NEVER judge by title, star count, or marketing copy — fetch the actual syllabus / channel content / docs and assess it. Default audience: AI-savvy NON-developer who is not learning to code.

## What to actually check (fetch the source first)
1. **Real content** — read the syllabus / sample videos / docs. What does it concretely teach?
2. **Non-developer fit (1–5)** — does it require Python or coding? 5 = fully no-code. Flag any "requires Python" as skip-for-non-coder (or "watch lectures for concepts only").
3. **Cost & model** — free / one-time / subscription. Note the real number.
4. **Recency** — is it current (this year's models/tools) or stale?
5. **Depth & placement** — foundational / intermediate / advanced; where it slots in a path.
6. **Grift test (critical):** Flag the pattern of *thin free content funneling into an expensive ($1k+) community/course with sales-call-gated pricing, high-pressure tactics, opaque refunds, or unverifiable income claims.* A cheap (~$50–200/mo) optional community behind genuinely substantial free content is fine; a $5k+ "accelerator" hidden behind a sales call is a red flag.

## Output format (per resource)
- Name + provider + URL
- What it actually teaches
- Cost
- Non-dev fit (1–5) + any coding caveat
- Recency
- Slots: foundational / intermediate / advanced
- **Verdict:** recommend / skip / "free part only" — with the one-line reason

End with a ranked shortlist and, if relevant, the single best free option. Be blunt about grift; the learner asked for honesty, not diplomacy.

## Known-good anchors (as of 2026, re-verify)
- Free & legit: Anthropic Academy, Make Academy, DeepLearning.AI (concepts; labs need Python), YouTube: Nate Herk / Cole Medin (n8n, builds), Nick Saraev (business model).
- Treat with skepticism: any "AI Automation Agency accelerator" priced $5k+ behind a sales call (e.g. take the free content only).
